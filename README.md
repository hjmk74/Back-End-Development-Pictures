# Back-End-Development-Pictures

A Flask-based Pictures microservice developed as part of the IBM Back-End Development Capstone project.

## Environment Setup

1. Create this repository from the provided IBM Developer Skills Network template.
2. Open a terminal in the project directory.
3. Run the environment setup script:

   ```bash
   bash ./bin/setup.sh
   ```

4. The setup script completes successfully and prepares the project environment.
5. Use Python 3.9.x.
6. The virtual environment for this project is named `backend-pics-venv`.

## Run the application

Activate the project virtual environment, install the project requirements if needed, and start the Flask application using the provided project instructions.

## Tests

Run the API tests with:

```bash
pytest
```
